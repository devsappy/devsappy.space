# Sappy Portfolio

![Portfolio Design](./image.png)

## What is this website about?

This is a premium, single-page (with a scrollable projects section) personal portfolio built for **Sappy**, a highly skilled **Website Developer** and **Video Editor** based in India.

The purpose of this website is to act as a sleek digital business card and a central hub for potential clients to view Sappy's expertise and past work. 

## Key Features

- **Immersive Hero Section:** A perfectly framed, viewport-locked landing screen that immediately captures attention. It features a custom beige-and-dark aesthetic with thin, elegant borders.
- **Micro-Animations:** The inline icons (profile picture, developer icon, Premiere Pro icon, and India flag) pop into existence sequentially when the page loads, and then smoothly transition into a continuous left-to-right see-saw floating animation.
- **Projects Grid:** A dedicated `/projects` route that features a responsive grid of Sappy's selected works (Pixel Forge, Coffee 3D, Vanta, Kiln Forge, Cafe Kaleido, Chatterify).
- **Interactive Cards:** Hovering over any project card triggers a sweeping color-inversion animation that slightly lifts the card off the page, providing a premium tactile feel.
- **Partner Marquee:** A fixed footer bar showcasing tools and partner companies (Nblik, Brianly, Od Solution, Vibe Engine, Chatterify).

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Vanilla CSS (Global variables, CSS Grid, Flexbox, Keyframe Animations)
- **Deployment:** Vercel (Ready)

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)
